# Inspired Startup Prototype

Protótipo criado a partir do repositório `startup-spark-base` como inspiração para melhorias no site `memory-grace`.

Inclui:
- Header responsivo com menu móvel simples
- Hero com CTAs
- Seção de recursos com animações de entrada
- Carrossel acessível (auto-scroll com requestAnimationFrame, pausa em hover)

Como testar localmente:

```bash
cd inspired-startup
python3 -m http.server 8000
# Abra http://localhost:8000
```
