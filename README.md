# Portfólio de Desenvolvedor

Este é um site de portfólio de página única, limpo e moderno, construído com HTML, CSS e JavaScript puros. O design é responsivo e apresenta um tema escuro elegante, ideal para exibir projetos de software.

## Features

- **Tema Escuro Profissional:** Paleta de cores que valoriza o conteúdo.
- **Galeria de Projetos Dinâmica:** Projetos são carregados com links diretos para os repositórios do GitHub.
- **Lightbox para Imagens:** Visualização de imagens dos projetos em tela cheia sem sair da página.
- **Animações de Scroll:** Seções de conteúdo aparecem suavemente conforme o usuário rola a página.
- **Navegação Inteligente:** O menu de navegação destaca a seção que está atualmente visível.
- **Design Responsivo:** O layout se adapta a diferentes tamanhos de tela, de desktops a celulares.
- **Estrutura de Arquivos Organizada:** Código-fonte e assets são separados em pastas para fácil manutenção.

## Como Executar

Como este é um projeto front-end estático, não há necessidade de um servidor ou dependências.

1.  Clone ou baixe este repositório.
2.  Abra o arquivo `index.html` em um navegador de sua escolha (Google Chrome, Firefox, etc.).

## Tecnologias Usadas

- **HTML5**
- **CSS3** (com Variáveis CSS, Flexbox e Grid Layout)
- **JavaScript (ES6+)**
    - **Intersection Observer API** para animações de scroll e navegação inteligente.
